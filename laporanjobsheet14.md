## Pertanyaan:
1.Karena BST memiliki aturan data kiri lebih kecil dan data kanan lebih besar dari parent, sehingga pencarian tidak perlu memeriksa semua node dan menjadi lebih cepat.
2.Atribut left dan right digunakan untuk menyimpan alamat anak kiri dan anak kanan dari suatu node.

3a. Atribut root digunakan untuk menyimpan node akar (root) yang menjadi titik awal seluruh operasi pada tree.

3b. Nilai awal root adalah null karena tree masih kosong.

4.Jika tree kosong, node baru yang ditambahkan akan langsung menjadi root.
5.Baris program tersebut digunakan untuk menentukan apakah data baru ditematkan ke subtree kiri atau subtree kanan berdasarkan perbandingan nilai IPK.
6.Saat node yang memiliki dua anak dihapus, program mencari successor (nilai terkecil pada subtree kanan) menggunakan getSuccessor(). Successor menggantikan posisi node yang dihapus agar struktur BST tetap benar.
